Como restauro minha biblioteca de jogos após uma reinstalação?

Sincronize seus salvamentos na nuvem através das configurações do Launcher Iara antes de iniciar uma nova instalação.

Transações multiplataforma são suportadas para DLCs?

A maioria dos títulos suporta compra cruzada entre PC e Console quando vinculados ao seu ID Iara.

Requisitos de sistema para Sky Dust

Recomendamos no mínimo uma Nvidia GeForce RTX 2060 / AMD Radeon RX 5600 XT para uma experiência ideal.
